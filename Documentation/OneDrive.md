# OneDrive for Business

## Overview

OneDrive for Business is Microsoft's cloud-based file storage and synchronization service included with Microsoft 365. It allows users to securely store, access, synchronize, and share files from any device while integrating with other Microsoft 365 services such as SharePoint Online, Microsoft Teams, and Office applications.

---

## Key Features

- Cloud file storage
- File synchronization
- Secure file sharing
- Real-time collaboration
- Version history
- File recovery
- Offline access
- Cross-device access

---

## Storage and Synchronization

OneDrive automatically synchronizes files between a user's device and the cloud, ensuring that the latest version is available across all connected devices.

Users can:

- Upload files
- Download files
- Synchronize folders
- Access files offline
- Restore previous file versions

---

## File Sharing

OneDrive supports secure file sharing with:

- Internal users
- External users (if enabled)

Sharing options include:

- View only
- Edit permissions
- Password-protected links (where supported)
- Expiration dates for shared links (depending on license)

---

## Version History

Version History allows users to:

- View previous versions of files
- Restore earlier versions
- Recover from accidental changes
- Support collaborative editing

---

## Common Administrative Tasks

Microsoft 365 administrators commonly perform:

- Manage OneDrive storage limits
- Restore deleted files
- Restore deleted OneDrive accounts
- Configure sharing settings
- Monitor storage usage
- Manage user access
- Review OneDrive activity reports

---

## Security Features

OneDrive for Business supports:

- Microsoft Entra ID authentication
- Multi-Factor Authentication (MFA)
- Role-Based Access Control (RBAC)
- Data Loss Prevention (DLP)
- Sensitivity Labels
- Retention Policies
- Audit logging

---

## Best Practices

- Enable Multi-Factor Authentication for users.
- Apply least privilege when granting access.
- Review external sharing settings regularly.
- Monitor storage usage and user activity.
- Encourage users to organize files with meaningful folder structures.
- Use retention policies for important business data.
