# Microsoft 365 Security and Compliance

## Overview

Microsoft 365 Security and Compliance provides tools and services to help organizations protect data, manage identities, detect threats, and meet regulatory requirements. These capabilities help safeguard users, devices, applications, and business information across the Microsoft 365 environment.

---

## Why Security and Compliance are Important

Microsoft 365 Security and Compliance help organizations:

- Protect sensitive business data.
- Secure user identities and devices.
- Detect and respond to security threats.
- Meet regulatory and compliance requirements.
- Reduce the risk of data loss.

---

## Key Security Features

### Multi-Factor Authentication (MFA)

MFA adds an extra layer of security by requiring users to verify their identity using more than one authentication method.

Examples include:

- Microsoft Authenticator
- SMS verification
- Phone call
- Hardware security key

---

### Conditional Access

Conditional Access policies allow administrators to control access based on:

- User or group
- Device compliance
- Location
- Application
- Sign-in risk

---

### Microsoft Defender

Microsoft Defender provides protection against:

- Malware
- Phishing attacks
- Ransomware
- Email threats
- Endpoint threats

---

### Microsoft Purview

Microsoft Purview helps organizations:

- Classify sensitive information
- Apply retention policies
- Manage compliance
- Prevent data loss
- Perform eDiscovery

---

## Compliance Features

Microsoft 365 includes tools for:

- Audit Logs
- Retention Policies
- Data Loss Prevention (DLP)
- eDiscovery
- Sensitivity Labels
- Compliance Reports

---

## Common Administrative Tasks

Microsoft 365 administrators commonly perform:

- Enable Multi-Factor Authentication
- Configure Conditional Access policies
- Review audit logs
- Monitor security alerts
- Configure retention policies
- Apply sensitivity labels
- Review compliance reports
- Investigate security incidents

## Best Practices

- Enable MFA for all administrator accounts.
- Review audit logs regularly.
- Apply Conditional Access policies.
- Follow the principle of least privilege.
- Monitor security alerts proactively.
- Review compliance settings periodically.
