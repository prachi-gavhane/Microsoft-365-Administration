# Microsoft 365 License Management

## Overview

Microsoft 365 licenses determine which Microsoft services and features users can access. Administrators are responsible for assigning, modifying, and managing licenses to ensure users have the appropriate applications and cloud services required for their roles.

Proper license management helps organizations optimize costs, maintain compliance, and provide users with the resources they need.

---

## Why License Management is Important

Effective license management helps organizations:

- Provide users with required Microsoft 365 services.
- Control software costs.
- Maintain license compliance.
- Simplify user onboarding and offboarding.
- Prevent unused license consumption.

---

## Common Microsoft 365 License Types

### Microsoft 365 Business Basic

Includes:

- Exchange Online
- Microsoft Teams
- OneDrive
- SharePoint Online
- Web versions of Office applications

---

### Microsoft 365 Business Standard

Includes:

- Everything in Business Basic
- Desktop Office applications
- Outlook
- Excel
- Word
- PowerPoint

---

### Microsoft 365 Business Premium

Includes:

- Everything in Business Standard
- Microsoft Intune
- Microsoft Defender for Business
- Advanced security features

---

### Microsoft 365 E3

Suitable for medium to large enterprises.

Includes:

- Desktop Office applications
- Exchange Online
- Teams
- SharePoint
- OneDrive
- Microsoft Entra ID P1
- Compliance and security features

---

### Microsoft 365 E5

Includes everything in E3, plus:

- Microsoft Defender XDR
- Microsoft Defender for Office 365
- Microsoft Entra ID P2
- Microsoft Purview advanced features
- Advanced security and compliance capabilities

## Common Administrative Tasks

Microsoft 365 administrators commonly perform:

- Assign licenses to new users.
- Remove licenses from inactive users.
- Modify assigned services.
- Monitor available licenses.
- Review subscription usage.
- Troubleshoot licensing issues.
- Manage product subscriptions.

---

## Common Licensing Issues

Examples include:

- No available licenses.
- Incorrect license assigned.
- User unable to access Microsoft 365 services.
- Delays in license provisioning.
- Subscription expiration.

---

## Troubleshooting Example

### Issue

A user was unable to access Microsoft 365 services after account creation.

### Troubleshooting Steps

- Verified the user account was created successfully.
- Checked whether a Microsoft 365 license had been assigned.
- Confirmed the correct subscription was available.
- Assigned the required license.
- Asked the user to sign out and sign back in after the license provisioning completed.

### Resolution

The assigned license provisioned successfully, and the user was able to access Microsoft 365 services.

---

## Best Practices

- Assign licenses based on job responsibilities.
- Remove licenses from inactive or offboarded users.
- Review license usage regularly.
- Monitor subscription availability.
- Use group-based licensing where appropriate.
