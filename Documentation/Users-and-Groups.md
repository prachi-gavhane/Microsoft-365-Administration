# Users and Groups

## Overview

Managing users and groups is one of the primary responsibilities of a Microsoft 365 Administrator. Administrators create user accounts, assign licenses, reset passwords, manage group memberships, and control access to Microsoft 365 services.

---

## User Management

Administrators can perform the following tasks:

- Create new users
- Update user information
- Reset passwords
- Block or unblock sign-in
- Delete users
- Restore deleted users
- Assign or remove licenses
- Manage user roles

---

## Creating a New User

Typical steps:

1. Open the Microsoft 365 Admin Center.
2. Navigate to **Users** > **Active users**.
3. Select **Add a user**.
4. Enter the user's details.
5. Assign the appropriate license.
6. Review and create the account.

---

## Password Management

Common tasks include:

- Reset user passwords
- Require users to change passwords at next sign-in
- Unlock user accounts
- Assist users with sign-in issues

---

## License Assignment

Administrators assign licenses based on business requirements.

Examples:

- Microsoft 365 Business Basic
- Microsoft 365 Business Standard
- Microsoft 365 Business Premium
- Microsoft 365 E3
- Microsoft 365 E5

Licenses can be assigned individually or through group-based licensing.

---

## Group Management

Microsoft 365 supports several group types:

### Microsoft 365 Groups

Used for collaboration across Microsoft Teams, Outlook, SharePoint, and Planner.

### Security Groups

Used to manage permissions for users and resources.

### Distribution Lists

Used to send email messages to multiple users through a single email address.

### Mail-enabled Security Groups

Provide both email distribution and permission management.

---

## Common Administrative Tasks

Microsoft 365 administrators commonly perform:

- Create user accounts
- Assign licenses
- Reset passwords
- Create Microsoft 365 Groups
- Manage Security Groups
- Add or remove group members
- Disable inactive accounts
- Review user activity

---

## Best Practices

- Follow the principle of least privilege.
- Assign licenses based on user requirements.
- Remove unused accounts promptly.
- Review group memberships regularly.
- Enable Multi-Factor Authentication (MFA) for users where appropriate.
