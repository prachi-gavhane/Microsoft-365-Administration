# Microsoft 365

## Overview

Microsoft 365 is a cloud-based productivity and collaboration platform developed by Microsoft. It combines Office applications, cloud services, security solutions, and device management into a single subscription.

Microsoft 365 enables organizations to improve communication, collaboration, productivity, and security while reducing the need for on-premises infrastructure.

---

## Core Components

Microsoft 365 includes several services:

- Microsoft Entra ID
- Exchange Online
- Microsoft Teams
- SharePoint Online
- OneDrive for Business
- Microsoft Defender
- Microsoft Purview
- Microsoft Intune
- Microsoft 365 Apps

---

## Key Features

- Cloud-based productivity
- Email and calendar services
- File storage and sharing
- Real-time collaboration
- Identity and access management
- Endpoint management
- Security and compliance
- Built-in scalability

---

## Common Administrative Tasks

Microsoft 365 administrators commonly perform:

- Create and manage users
- Assign and remove licenses
- Reset passwords
- Configure Exchange Online
- Manage Microsoft Teams
- Configure SharePoint permissions
- Manage OneDrive storage
- Monitor service health
- Review audit logs
- Perform administrative tasks using PowerShell
