# SharePoint Online

## Overview

SharePoint Online is Microsoft's cloud-based collaboration and document management platform included with Microsoft 365. It enables organizations to securely store, organize, share, and manage documents while supporting collaboration across teams and departments.

SharePoint Online integrates with Microsoft Teams, OneDrive for Business, Exchange Online, and Microsoft Entra ID.

---

## Key Features

- Document management
- Team sites
- Communication sites
- Document libraries
- Version history
- File sharing
- Permission management
- Search functionality
- Integration with Microsoft 365 applications

---

## Site Types

### Team Site

A Team Site is designed for collaboration among team members.

Common uses include:

- Project documentation
- Department collaboration
- Shared files
- Task management

---

### Communication Site

A Communication Site is designed to share information with a broader audience.

Common uses include:

- Company announcements
- Policies and procedures
- Internal news
- Knowledge sharing

---

## Document Libraries

Document Libraries provide centralized storage for files.

Features include:

- Version control
- Metadata
- File check-in/check-out
- Co-authoring
- Search

---

## Permission Levels

Common SharePoint permission levels include:

- Full Control
- Edit
- Contribute
- Read
- View Only

Permissions can be assigned to users or groups.

---

## Common Administrative Tasks

Microsoft 365 administrators commonly perform:

- Create SharePoint sites
- Manage site permissions
- Create document libraries
- Configure external sharing
- Restore deleted files
- Monitor storage usage
- Manage site collections
- Review site activity reports

---

## Security Features

SharePoint Online supports:

- Microsoft Entra ID authentication
- Multi-Factor Authentication (MFA)
- Role-Based Access Control (RBAC)
- Data Loss Prevention (DLP)
- Sensitivity Labels
- Retention Policies
- Audit logging

---

## Best Practices

- Assign permissions using groups instead of individual users.
- Apply the principle of least privilege.
- Review external sharing settings regularly.
- Enable version history for important document libraries.
- Monitor storage utilization and site activity.
- Use retention policies for business-critical documents.
