# Microsoft Entra ID

## Overview

Microsoft Entra ID (formerly Azure Active Directory) is Microsoft's cloud-based identity and access management (IAM) service. It enables organizations to securely manage user identities, authentication, authorization, and access to Microsoft 365, Azure, and thousands of third-party applications.

---

## Why Microsoft Entra ID?

Microsoft Entra ID helps organizations:

- Manage user identities.
- Authenticate users securely.
- Control access to applications.
- Enable Single Sign-On (SSO).
- Protect accounts with Multi-Factor Authentication (MFA).
- Support Zero Trust security principles.

---

## Key Features

### User Management

Administrators can:

- Create users
- Update user information
- Delete users
- Reset passwords
- Block or unblock sign-in
- Assign administrative roles

---

### Group Management

Supports:

- Security Groups
- Microsoft 365 Groups
- Dynamic Groups

Groups simplify permission and license management.

---

### Single Sign-On (SSO)

Allows users to sign in once and securely access multiple Microsoft and third-party applications without repeatedly entering credentials.

---

### Multi-Factor Authentication (MFA)

Adds an additional layer of security by requiring users to verify their identity using more than one authentication method.

Examples include:

- Microsoft Authenticator
- SMS verification
- Phone call
- Hardware security key

---

### Conditional Access

Conditional Access policies help administrators control access based on conditions such as:

- User or group
- Device compliance
- Location
- Risk level
- Application

---

### Role-Based Access Control (RBAC)

Microsoft Entra ID provides built-in administrator roles, including:

- Global Administrator
- User Administrator
- Helpdesk Administrator
- Exchange Administrator
- Security Administrator

RBAC ensures users receive only the permissions required for their responsibilities.

---

## Common Administrative Tasks

Microsoft 365 administrators commonly perform:

- Create and manage users
- Manage security groups
- Reset passwords
- Enable or disable MFA
- Assign administrator roles
- Configure Conditional Access policies
- Review sign-in logs
- Monitor identity security

---

## Benefits

- Secure identity management
- Centralized authentication
- Improved security
- Single Sign-On
- Simplified administration
- Integration with Microsoft 365 and Azure

---

## Best Practices

- Enable Multi-Factor Authentication for administrators.
- Apply the principle of least privilege using RBAC.
- Review sign-in logs regularly.
- Use Conditional Access policies to strengthen security.
- Remove unused accounts promptly.
